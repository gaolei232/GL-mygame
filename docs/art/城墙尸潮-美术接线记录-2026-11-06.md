## 4. 修掉的 5 个问题（都不是"感觉不好"，是可量化的错误）

### 4.1 `draw_nine_patch` 在 CanvasItem 上不存在
Godot 4 把九宫格归 `StyleBox`，`CanvasItem` 只提供 `draw_texture_rect` / `draw_texture_rect_region`。
首版调用直接报 `Invalid call. Nonexistent function 'draw_nine_patch'`。
**改法**：在 `HudSkin` 里自实现 3×3 切片（`draw_np`），参数是边距 + tint，25 行，不依赖 `StyleBoxTexture` 的 tint 能力。控件层的按钮/面板则直接用 `StyleBoxTexture`（那边本来就该用 StyleBox）。

### 4.2 破口警示 alpha 被二次相乘，等于没画
`ui_danger_edge_v1` 资产**自身边缘 alpha 峰值已是 89/255 ≈ 0.35**（清单要求就是这个值）。
我却又用 modulate 0.18–0.35 去乘，有效 alpha 只剩 0.06–0.12，肉眼几乎不可见。
**改法**：modulate 提到 0.55–1.0，有效峰值回到 0.35 附近。这是"贴图自带 alpha 时 modulate 不是调透明度、是叠乘"的典型坑。

### 4.3 墙格贴图在世界坐标里按 48px 画，比敌人还抢眼
第一版把 24×18 的墙格按 2× 放大到 48×36 当世界标记，截图里像贴在墙上的便利贴。
**改法**：回到源图原尺寸 24×18 + alpha 0.9，退到次体层。原 5px 细血条同时在 24×18 三态格下解决了"读不出比例"的问题。

### 4.4 `ui_reward_card_frame_v1` 当面板底，整套 UI 翻白
第 2 阶段先把奖励卡外框套成波末面板底，实拍发现：它是 **220×300 的竖卡**、内部底色浅灰，
套到 300×250 的横向面板上会突然翻成亮色，与全局暗色 UI 断裂，标签文字也失去对比。
**改法**：撤回换皮，面板底统一用堡垒面板。第 4 阶段已按它本来的尺寸语义落地：三张 220×300 原尺寸横排居中，卡框按参考灰 200 归一染色到 0.62 倍（≈124 暖钢灰），与暗场景同族。
**教训**：这张图的语义是"竖卡 220×300"，任何横向拉伸场景都不该用它；染色时倍率必须除以实测基准灰 200，不是想当然按 255 算。

### 4.5 城内地面用 44×44 方板，四角把广场砖铺到了城墙外面
要让方板完全盖住半径 22 的墙圈，边长必须 44，但四个角会伸到 31m——实拍可见城墙外侧也是广场砖，"城内/城外"两套地面的边界形同虚设。
**改法**：内层改 `CylinderMesh` 圆盘（半径 22、64 分段、厚 0.04），贴合墙圈，里头不缺、外头不漏。注意圆盘顶盖 UV 是 0..1 覆盖整个直径，铺贴数要按**直径**算（44/9≈5），不是按边长。

## 5. 已知取舍（都不是 bug，是有意选择）

| 取舍 | 原因 |
|---|---|
| 墙段破损程度只分 3 档，不显示精确百分比 | 24×18 的格子上读不出百分比；顶栏刻度条已给总量读数 |
| 破口三角标不随墙段朝向旋转 | `draw_texture_rect` 不带旋转；如需朝向要换 `draw_set_transform` |
| 资源图标 20px 由 96px 线性缩放，略微发软 | 图标导入关掉了 mipmap（保锐利边框）；静态 HUD 不闪。若嫌软，改 `.import` 开 mipmap 即可，一行 |
| 墙段标记在屏幕上下 96px 内被裁掉 | 沿用原有"不让世界标记压住 HUD"的规则，未改 |
| 按钮 hover 无专属贴图，复用 normal + 字体提亮 | 资产只出了 normal/pressed/disabled 三态，没有 hover；造一个 hover 会产生与美术不一致的第四种外观 |
| 面板底跟随 VBox 包围盒，而非换成 PanelContainer | PanelContainer 会改变既有锚点/定位行为，用独立 `Panel` 跟随包围盒风险最低 |
| 地面贴图重复感仍在（每 9m 一块同款纹样） | 单张可平铺贴图 + 无 shader 的情况下无法做 4 向随机铺贴；9m 已让纹理读成"地面起伏"而非"地毯方块"。彻底解决要写 UV 打散 shader 或叠 decal，属第 4 阶段 |
| `env_sky_dusk_v1` 接了但基本看不见 | 相机是俯视 2.5D、地面平面 120m 铺满取景框，天空只剩屏幕最上方一条 1% 的窄缝。它适合"地平线入镜"的构图；当前保留接线（无害，相机若拉远即生效），但**不应算作已产生视觉收益** |

## 7. 复跑命令

```bash
GODOT="D:/GODOT/Godot_v4.7.2-stable_win64_console.exe"

# 1) 新增 class_name 脚本后，先让引擎重扫注册（否则报 "Could not find type HudSkin"）
"$GODOT" --headless --import --path .

# 2) 无错检查
"$GODOT" --headless --path . --quit-after 60 2>&1 | grep -iE "SCRIPT ERROR|Parse Error"

# 3) 画面验证（窗口渲染，输出到 shots/）
"$GODOT" --path . --script res://tests/visual_capture.gd
```

> 注意：`--headless` 不会绘制，无法验证画面；画面必须用 `visual_capture.gd` 走窗口渲染。
