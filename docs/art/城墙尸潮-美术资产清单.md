- 运行时资产共 **62 项**：P0 **28 项**、P1 **22 项**、P2 **12 项**。
- 当前缺口 **62 / 62**（`view/*` 全部为程序化几何，`shots/*` 为占位截图，无任何正式美术资产）。

## 1. 命名规范（四段式，全项目统一）

```
<类别前缀>_<对象>_<变体或状态>_v<版本>.<扩展名>

char_hero_normal_v1.png          # 玩家常态
mon_walker_normal_v1.png         # 普通感染者
env_wall_rampart_broken_v2.png   # 城墙段破口态
ui_panel_bastion_normal_v1.png   # 面板底
icon_coin_small_v1.png           # 金币图标
fx_hit_spark_normal_v1.png       # 命中火花
mdl_wall_segment_a_v1.glb        # 3D 模型
tex_wall_rampart_albedo_1k.png   # 贴图
```

前缀：`char / mon / env / ui / icon / fx / anim / mdl / tex / font / img`。
禁止：中文名、空格、`最终版`、`未命名`、`@v2`（版本分隔符一律 `_vN`）。

**工具链（v1.1 补充）**

```bash
PY=python
$PY tools/keyout_flood.py <img> --tol 20 --report     # 深色资产抠图：只删外轮廓，内部空洞 = 0
$PY tools/keyout_flood.py <img> --tol 14              # 主体极暗时收紧容差
$PY tools/tex_tune.py <img> --target-l 30 --patch-wm  # 贴图按目标明度校正 + 擦水印
$PY tools/icon_norm.py <sheet> --names a,b,c --outdir art/assets/icon --area 0.28
                                                      # 多格图自动分件 + 按面积归一 + 96/192/512 三档
```

依赖 Pillow（已装在托管虚拟环境）。生成图的背景色每次不同（实测 `#101618`–`#652E36`），`keyout_flood` 按四角自动采样；贴图明度实测普遍比要求亮 10–25 个百分点，必须用 `tex_tune` 反解 gamma 压回目标值。
