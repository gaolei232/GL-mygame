# 建造系统设计（2026-11-10）

> 范围：为《城墙尸潮 G-A》新增木箱 / 背包 / 城墙段 / 炮台四种可建造物，覆盖放置、建造、拆除、上限、耐久、摧毁掉落、回收，以及与背包、资源、存档、HUD 的联动。
>
> 数值单源：`data/buildings.json`；规则实现：`core/systems/build_system.gd`；UI：`ui/build_panel.gd`、`ui/crate_panel.gd`；表现：`view/build_layer.gd`。

---

## 0. 结论

1. **四件建造物全部落地**：木箱（仓库）、背包（随身扩容）、城墙段（每波 1 段）、炮台（自动炮）。
2. **背包采用方向 1**：+10 格 / 420 金等价，最多 2 个（5×2 → 5×4 → 5×6，容量 10 → 20 → 30）。理由见 §12。
3. **城墙段按新表收敛为「每波 1 段」**，替代 2026-11-09 的「段数无上限」；破口重建（30 砖 + 150 金）不受此限。
4. **木箱不限数量**，但受砖块收入约束；被摧毁后箱内 100% 掉落、60s 消失、可原地重建且**继承原计价序号**。
5. **拆除返还 50% 建造资源**；木箱内容物 100% 掉落。拆除自建城墙**不退本波建造名额**，防止「建了拆、拆了建」绕过闸门。

## 3. 放置规则

### 3.1 通用

- **仅建设期**可建造/拆除；战斗期只保留破口重建（`E`）与修墙/修建造物。
- 建造不要求玩家贴近：沿用原「光标在允许范围内即可放置」的手感；建设期活动范围仍限制在城墙圈内。
- 已存在的初始 7 段城墙是地形，**不可拆除**；自建段可拆。

### 3.2 木箱 / 炮台（城内）

| 检查 | 规则 | 提示 |
|---|---|---|
| 水晶 | 距原点 ≥ `crystal_radius + 1.5m`（默认 5.5m） | 离水晶太近 |
| 城墙圈 | 距原点 ≤ `wall_radius − 2.0m`（默认 16m） | 只能建在城墙内 |
| 城墙占位 | 与任一段墙的垂距 ≥ 1.5m（炮台 ≥ 1.9m，含自身半径与墙半厚） | 与城墙重叠 |
| 建造物占位 | 两中心距 ≥ 半径 A + 半径 B + 0.2m | 与其他建造物重叠 |

木箱半径 0.6m，炮台半径 1.0m；均取 footprint 长边的一半。木箱可紧贴炮台/木箱，但不能叠进去。

### 3.3 城墙段（城内自由放置）

| 检查 | 规则 | 提示 |
|---|---|---|
| 水晶 | 距原点 ≥ `crystal_radius + 6m`（默认 10m） | 离水晶太近 |
| 范围 | 距原点 ≤ `wall_radius − city_margin`（默认 16m，即城墙内） | 只能建在城墙内 |
| 已有墙 | 与任一段墙垂距 ≥ 2.0m | 这里已有城墙 |
| 建造物 | 与木箱/炮台不重叠（墙半长 + 半径 + 1m） | 与其他建造物重叠 |
| 每波名额 | `wall_built_this_wave < 1` | 本波城墙段已建满（1/1） |

新建段沿用原墙圈曲率：`tangent = pos.normalized().orthogonal()`，半长 = `(arc × ring / 7) / 2 + 0.1`，与初始 7 段同规格。

### 3.4 背包

`placement = "self"`：不选点，点击建造卡片立即扩容；无地形限制。

### 3.5 自由建造模式（V）

- 建设期按 `V` 进入/退出「自由建造模式」。
- 进入后默认沿用上次选过的可放置建造物（没有则木箱）；`5/6/7/8` 随时切换。
- 左键在光标处放置，**成功后不退出模式**，可以继续连续放置；资源不足/位置非法时只给提示，也不退出。
- `V` / 右键 / `Esc` 退出；`6`（背包）是即时扩容，不打断当前放置选择。
- 所有建造物（含城墙段）的落点都限定在城墙圈内（`radius ≤ 16m`）；放置仍是像素级自由选点，不做网格吸附。

## 4. 建造与拆除流程

### 4.1 建造

```
建设期 → 按 V 进入自由建造（或点击左侧建造卡片 / 按 5/6/7/8）
      → 木箱/城墙/炮台跟随光标显示绿色/红色预览，位置限定在城墙内
      → 左键在光标处建造；成功后保持模式，可继续连续放置
      → V / 右键 / Esc 退出；背包卡片点击即建造（无放置，不打断模式）
```

- 失败时**不扣资源**，通过 `NOTICE` 给出原因；成功时扣费、生成实例、发 `BUILDING_BUILT`。
- 城墙段成功后 `wall_built_this_wave += 1`；木箱/炮台成功后写入计价序号。
- 木箱序号分配：优先复用 `crate_free_indices` 的最小值，否则用 `crate_next_index` 并自增。
- 炮台序号只增不减；被毁后重建按下一档价格。
- 背包：`bag_rows = base_rows + backpack_built × 2`，`bag_capacity = bag_cols × bag_rows`，随后 `InventorySystem.repack()`。

### 4.2 拆除

```
建设期 → X 进入拆除模式 → 光标指向木箱/炮台/自建墙段
      → 左键拆除；右键 / Esc 退出
```

- **返还**：实付 coin / brick / metal 的 50%（四舍五入）；升级花费不返还。
- **木箱**：内容物 100% 掉落（同摧毁），序号释放；返还 50% 建造资源。
- **炮台**：返还 50% 建造资源；无内容物。
- **自建城墙段**：返还 50% 建造资源；**不退还本波 1 段名额**；后续段索引前移，渲染节点同步回收。
- **初始城墙**：拒绝并提示「初始城墙是地形，不能拆除」。
- **背包**：不可拆除（随身扩容）。

## 5. 上限与耐久

| 建造物 | 数量上限 | 耐久/生命 | 备注 |
|---|---|---|---|
| 木箱 | 不限（0） | 200 HP | 受砖块收入约束；全周期砖 163，理论上限约 10 个，扣除修墙/重建实际 6–7 个 |
| 背包 | 2 | 无 | 容量 10 → 20 → 30 |
| 城墙段 | 每波 1 段 | 12,143 HP | 破口重建不占名额；升级 ×1.35/级，最多 Lv3 |
| 炮台 | 3 | 800 HP | 45 DPS / 射程 16m |

- 木箱/炮台可被锤子修复：每次 1 砖，回复量 = 锤子等级对应 `atk × repair 修正`（Lv1 约 900），不超过上限。
- 木箱 200 HP 一锤回满；炮台 800 HP 一锤回满。
- 城墙段仍走原修墙规则（1 砖 = 900 HP 起，随锤子等级提升）。

## 6. 木箱仓库（25 格）

- 5×5 = 25 格；**资源按堆叠占 1 格**（单堆上限 9,999），**物品每件占 1 格**（不按稀有度占 1×2/2×2；这是仓库与随身背包的刻意差异）。
- 存取半径 **3.0m**：靠近后 HUD 底部提示「R 存取木箱 #N · x/25 格」；按 `R` 打开模态仓库。
- 仓库面板：
  - 左：5×5 格；左键取出整堆资源/整件物品。
  - 右：金/砖/金属/弹药各一行「存 100 / 取 100」，并显示持有/箱内数量；背包物品逐件「存入」；「全部存入」。
  - `R` / `Esc` / 关闭按钮退出；打开时冻结 sim（与背包一致）。
- 背包满时取出物品会失败并保留格内物品；箱满时存入失败且不扣资源。

## 7. 摧毁、掉落与回收

### 7.1 木箱

| 项 | 规则 |
|---|---|
| 触发 | HP ≤ 0（敌人攻击 / 自爆 AOE / 行进碰撞） |
| 掉落 | 箱内 **100%**，按格生成掉落物；资源堆 / 物品均保留原数量/原 uid |
| 散落 | 以箱心为圆心、半径 **1.5m** 内随机；每格 1 件，最多 25 件 |
| 保留 | **60s**；到期消失 |
| 拾取 | 玩家进入 **1.2m** 自动拾取；资源直接入账，物品进背包（背包满则留在原地） |
| 占位 | 立即释放，可原地重建 |
| 计价 | 释放原序号；重建优先用最小空闲序号，**按原序号价格**（例如 #2 被毁后重建仍是 222 金） |
| 表现 | 木箱销毁爆点 + 掉落小球；最后 5s 闪烁；`DROP_PICKED` 飘字/提示 |

### 7.2 炮台

- 摧毁后移除，原地生成 **4 金属** 掉落（`salvage_metal=4`，60s，自动拾取）。
- 不返还建造资源；手动拆除才返还 50%。

### 7.3 城墙段

- 被敌人打到 0 HP = **破口**，不产生掉落；保留破口状态，可用 `E` 以 30 砖 + 150 金重建（建设期/战斗期均可）。
- 自建段被摧毁后仍是 `WallSegment`，不会从存档/墙列表消失；破口段不能升级，但可重建。

### 7.4 仇恨与伤害来源

- **木箱 0.3**：已破口进入城内的敌人，每只本波掷一次骰；约三成会主动拆箱，其余按原逻辑拆墙/攻水晶。掷失败后本波不再考虑木箱（`target_building = -2`）。
- **炮台 0.6**：同上，约六成敌人会优先拆炮台。
- **城墙 1.0**：原逻辑不变。
- **行进碰撞**：敌人贴近任一建造物（半径 +0.5m）时，按 `e.dmg × 0.25 × dt / interval` 持续磨血，即使没有主动锁定。
- **自爆 AOE**：轰炸者在 3m 半径内对所有建造物造成 `e.dmg`；只有距墙 ≤3.2m 时才同时伤墙（避免城内自爆隔空炸墙）。
- **炮台**：战斗期自动索敌 16m 内最近敌人，每 1.0s 造成 45 伤害（总 DPS 45），可越墙射击；不消耗弹药。

## 8. 与现有系统的联动

### 8.1 背包

- 基础背包仍是 `items.json` 的 5×2=10 格（**不改基础容量**，避免破坏 P1-4 既有数值/测试）。
- 建造背包 +10 格 → `bag_rows` 4/6，`InventoryPanel` 自动按行数缩放格子（86px → 84px → 50.7px），5×6 不会溢出面板。
- 扩容后 `InventorySystem.repack()` 重排，已有物品不丢失。

### 8.2 资源

- 建造/拆除/炮台回收/木箱存取全部走 `state.coin/brick/metal/ammo` 与 `EconomySystem` 的同一套字段。
- 木箱掉落与仓库取出都计入同一资源池；没有独立货币。
- 商店/升级/修墙与建造共享资源，不存在「建造专用资源」。

### 8.3 存档

- `SaveSystem.capture/restore` 新增：`buildings`（含 25 格 `stored`、实付、序号、HP）、`drops`（含物品字典、ttl）、`backpack_built`、`bag_rows`、`crate_free_indices`、`crate_next_index`、`cannon_next_index`、`wall_built_this_wave`、`building_seq`、`drop_seq`。
- 墙段新增 `built/paid_coin/paid_brick/build_wave`，旧档缺字段按默认值（不可拆、0 实付）读入。
- `version` 仍为 1；旧档没有建造字段 → 视为空建造列表，向后兼容。
- 只在 SCOUT/BUILD/REWARD 自动落盘；掉落物也随档保存，避免「波末清场后掉落消失」。

### 8.4 阶段

- `PhaseMachine.enter(BUILD)` 重置 `wall_built_this_wave = 0`；`new_run` 清空全部建造物/掉落/计价序号/背包扩容。
- 掉落 60s 计时在 REWARD / VICTORY / DEFEAT 也继续走（`Sim.step` 对非 TITLE 阶段调用 `BuildSystem.step`），不会因阶段切换冻结。

## 9. 界面

### 9.1 建造面板（建设期常驻左侧）

- 位置：左侧 `x=18, y≈196`，宽 304、高 424；在资源列（y 84–180）与底栏（y 630）之间，不遮挡商店面板（右侧 x≈950）。
- 四张卡片，每张显示：
  - 序号 + 名称 + 当前数量/上限（`已建 3 · 不限` / `1/2` / `本波 0/1` / `2/3`）
  - 实付资源 + 金等价（如「金 150 + 砖 15 ≈240G」）
  - 状态：`✔ 可建造` / `✔ 立即扩容` / `▶ 自由建造中` / `✘ 金币不足（还差 90）` / `✘ 已达上限（3/3）` / `✘ 本波城墙段已建满（1/1）`
- 卡片在资源不足/上限时置灰；**位置非法不置灰卡片**，而是在选中后由光标提示与红色预览表达。
- 底部两个开关：「自由建造（V）」与「拆除（X）」；下方一行上下文提示。
- 未进入自由建造时提示「按 V 进入自由建造；或点击建造物卡片」；进入后提示「左键连续放置 · V / 右键 / Esc 退出」。

### 9.2 放置预览

- `view/build_layer.gd` 生成半透明 BoxMesh：
  - 合法：绿色 38% alpha；非法：红色 38% alpha。
  - 木箱 1.2³、炮台 2×1.8×2、城墙 6.9×3.5×1.2（按光标点切向旋转）。
- HUD 贴光标提示：
  - 合法：`自由建造 木箱   150 金 + 15 砖   [左键] 连续放置 · [V] 退出`
  - 非法：`建造 木箱 · 只能建在城墙内`
  - 拆除：`拆除 木箱 · 返还 50% 建造资源 + 箱内 100% 掉落`

### 9.3 仓库与 HUD

- 靠近木箱 3m：底部中央提示 `R 存取木箱 #N · x/25 格`。
- 仓库面板 880×560 居中，深色遮罩 + 5×5 格 + 资源行 + 背包物品滚动列表；打开时冻结 sim。
- 建造物在世界中：木箱 = 木色方箱 + 两道深色箍；炮台 = 深灰底座 + 圆柱炮塔 + 炮管（炮塔朝最近敌人平滑转向）；受击闪白/按 HP 变红；拆除模式悬停亮红。木箱/炮台受伤后，HUD 在头顶画 40×4 耐久条（满血且离玩家 >6m 时不画）。
- 掉落物：按资源色的小球，上下浮动；最后 5s 闪烁。

### 9.4 快捷键

| 键 | 作用 |
|---|---|
| `V` | 进入/退出自由建造模式 |
| `5` / `6` / `7` / `8` | 木箱 / 背包 / 城墙段 / 炮台 |

| 校验 | 结果 |
|---|---|
| 木箱 HP/G | 200 / 240 = **0.83 HP/G** |
| 城墙段 HP/G | 12,143 / 425 = **28.57 HP/G** |
| 修墙 HP/G | 900 / 6 = **150 HP/G** |
| 木箱 vs 城墙性价比 | 相差 **34×**（0.83 → 28.57）；修墙相差 **180×** |
| 木箱砖约束 | 全周期砖 163 / 15 = 理论上限 **10 个**；修墙与重建后实际 **6–7 个** |
| 首次可负担 | #1 W1（15 砖 ≤17）、#2 W2（30 ≤43）、#3 W3、#4 W4 可到 5 个、W5 收尾 6–7 个（按原表口径） |
| 背包单格成本 | 420/10 = **42 G/格**；木箱 #1 9.6 → #8 60.3 G/格；背包在 #6–#7 之间收敛，保留 3–4 倍随身溢价 |

## 11. 背包数值冲突的处理（方向 1）

原表背包是 180 金 + 5 金属 = 280 金等价 / +5 格 = **56 G/格**；木箱单格 9.6–16 G/格，且木箱不限量。固定位置在基地防御战里不是劣势，玩家会一直买木箱，背包在容量维度没有空间。

三个方向中采用 **方向 1**：

- **背包 +10 格 / 420 金等价（42 G/格），最多 2 个**。
- 实现为 `cost_coin=320 + cost_metal=5`（=420 等价），`add_slots=10`、`add_rows=2`、`growth=1.5`、`max_count=2`。
- 结果：第 1 个背包 42 G/格，第 2 个 63 G/格；木箱第 6 个 35.7、第 7 个 46.4、第 8 个 60.3 G/格 —— 背包在 #6–#7 之间收敛，既保留「随身、战斗中可换装」的溢价，又不会让木箱完全取代它。
- 不选方向 2（移出建造列表）：与本需求「四种可建造物」冲突。
- 不选方向 3（280 不动）：56 G/格 远贵于木箱，建造次数趋近 0，等于白占一个格子。
- **基础背包 10 格不变**；扩容只来自建造，避免改动 P1-4 的既有初始容量。

## 12. 与旧规则的差异

| 旧规则 | 新规则 | 原因 |
|---|---|---|
| 城墙段数无上限（2026-11-09） | **每波 1 段** | 本次四件建造物表明确 max_count「—（每波 1 段）」；用名额而不是价格做硬闸门，避免「越造越赚」的线性扩张 |
| 城墙可建到外圈 46m | **所有建造物限定城墙内（≤16m）** | 自由建造模式统一落点上限，避免墙建到玩家建设期够不到的外圈 |
| 选卡片后放一个就退出 | **V 进入自由建造，连续放置，V/右键/Esc 退出** | 需求：自由选择地点 + 快捷键 V |
| 背包固定 10 格、无扩容 | 建造背包 +10×2，上限 30 | 方向 1；P1-7 的「10→30」以建造物形式落地 |
| 建造只走 `E` / 右侧商店面板 | 左侧建造面板 + 放置预览 + 卡片状态 | 需求要求「清晰展示可建造物列表与当前可建造状态」 |
| 修墙只修城墙 | 锤子也可修木箱/炮台 | 建造物有耐久，必须有修复入口；沿用 1 砖/次的成本 |
| 无地面掉落物 | 木箱 100% 掉落、炮台回收 4 金属 | 需求要求「被摧毁后的掉落或回收逻辑」 |
| 无建造物仇恨 | 木箱 0.3 / 炮台 0.6 / 墙 1.0 | 防止木箱变成无代价肉盾；同时给「诱饵」玩法留空间 |

## 14. 已知限制与后续

1. 木箱仓库是**格位制**，物品每件 1 格，不沿用随身背包的 1×2/2×2 占位；这是为了让「25 格 / 25 件掉落」口径简单可验证。若后续要做「箱内也按形状占位」，需同时改掉落上限与 UI。
2. 拆除自建城墙不退还每波名额，避免绕过 1 段/波；如果产品希望「拆了可以重造」，需要改成「名额按当前存活自建段数」并补一条防刷断言。
3. 城墙段被摧毁后仍是破口段（不产生掉落），重建成本 30 砖 + 150 金沿用旧规则；如果后续想让「自建段」被毁后直接移除，需要处理存档索引与敌人 `target_wall` 重映射。
4. 炮台可越墙射击（沿用「墙不挡子弹」）；如果后续改成炮台也受墙体遮挡，需要给 `Combat` 增加墙体遮挡参数，而不是在 BuildSystem 里硬编码。
5. 掉落物只在玩家 1.2m 内自动拾取；如果后续希望「一键回收全部掉落」，需要加一个全屏按钮与背包容量预检。
6. 城墙段现在也只能建在城墙圈内（≤16m），不能再把外圈扩到 46m；如果后续要恢复「向外扩建城墙」，需要给城墙单独放开外圈上限，同时保留木箱/炮台的城内限制。
