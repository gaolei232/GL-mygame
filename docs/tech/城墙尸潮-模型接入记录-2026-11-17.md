## 2. 主角接入细节（`view/unit_layer.gd`）

1. **坐标**：`player_body` 是容器，原点在**脚底**；每帧 `target = Vector3(pos.x, TerrainHeight.at(pos.x,pos.y), pos.y)`（旧胶囊是中心 +0.9）。
2. **朝向**：模型面向 Godot **-Z**（Blender +Y）。`player_yaw = lerp_angle(player_yaw, atan2(-aim.x, -aim.y), delta*14)`，容器 `rotation.y = player_yaw`。从瞄准方向实拍能看到兜帽暗腔，方向正确。
3. **动画状态机**（优先级从高到低）：
   `hit`（受击 0.42s）→ `fire`（开火 0.70s）→ `walk`（`player_speed > 0.5`）→ `idle`。
   walk 的 `speed_scale = clamp(player_speed / 3.2, 0.7, 1.8)`，避免慢走/疾跑时脚频固定。
4. **开火**：不新增事件，复用现有 `EventBus.SHOT_FIRED`；`app/game_app.gd` 在该分支调 `units.play_player_fire()`，内部 `stop()` 后重播 `fire`。
5. **受击**：`hurt_flash` 上升沿 → 播一次 `hit`，并把 4 个网格 `material_override` 设为无光照红色（0.09s 内可读），结束置 null；兜底胶囊仍走旧的 `_set_color()`。
6. **翻滚**：容器只转 yaw；模型绕脚底 `rotation.x → 1.05` 前倾 + `scale.y → 0.86` 压扁（没有翻滚动作时的占位表现）。
7. **武器**：弩的位置 = `hand.R` 骨骼的 world 位置 + 瞄准方向 0.10m + 0.04m 抬高；朝向固定为 `atan2(aim.x, aim.y)`（与旧逻辑一致）。没有手骨/GLB 时回退旧独立摆放。
8. **瞄准条**：由胸口（+1.15m，会横穿模型）改到贴地 `y=0.06`，尺寸收成 `0.10×0.02×1.4`，颜色暖白。
9. **兜底**：`HERO_SCENE` 不存在/加载失败 → `_make_fallback_player()` 返回旧胶囊，`hero_uses_glb=false`，所有 GLB 分支自动跳过。

## 3. 水晶接入细节（`view/world_builder.gd`）

1. `USE_CRYSTAL_MESH = true` + `CRYSTAL_SCENE`；`_add_crystal()` 先试 GLB，失败才走旧锥台。
2. 取 `GEO_Crystal_Diamond`（MeshInstance3D）作为可动节点：**只有它**做受击染色、浮动（`sin(t)*0.10`）与缩放（`0.92+0.08*ratio`）；`GEO_Base_Steps` 完全静止。
3. HP 染色：晶体 4 个材质各 `duplicate()`（不改导入缓存），记录 `base_albedo/base_emission`；每帧 `albedo = base.lerp(hurt_red, (1-ratio)*0.85)`，emission 同色，且 `emission_energy_multiplier = 0.9 + (1-ratio)*1.2`（残血发红光）。
4. 坐标：GLB 原点就是地面（台阶底 z=0），实例直接放世界原点，不再 +2.1m。
5. `_clear()` 里同时清空 `crystal_effects` 与节点引用，重开局（`world.build` 多次调用）不会泄漏。

## 5. 已知问题 / 取舍（不是 bug，是当前阶段的选择）

1. **武器是“位置跟手、朝向独立”**：弩没有真正插到 `BoneAttachment3D` 的手骨 socket 上（尝试过，骨骼局部轴与弩 +Z 不一致，容易转错）。开火/受击时手与弩可能轻微错位；要 1:1 贴合需要给右手加一个空物体 socket 并重导更精确的握持偏移。
2. **受击/死亡/翻滚没有专门动画**：受击用 `hit` 动作 + 全模红闪；翻滚仍是几何倾斜+压扁；死亡直接隐藏（旧逻辑）。
3. **目标环/瞄准条**：原瞄准条横穿胸口，已改贴地；若觉得不够醒目可改色/加长，但要注意会遮地面石板。
4. **动画速度**：walk 按实际速度缩放（0.7–1.8×），极快移动时仍可能看到滑步；跑步/冲刺动作还没做。
5. **水晶受击色**：20% 血时偏粉红，是 `lerp` 上限 0.85 的结果；若想更“暗红”需同时压 `albedo` 明度。
6. **QA 脚本会临时改状态**：`integration_capture_node.gd` 会把 `crystal_hp` 改到 20% 拍残血图、临时切相机，仅用于验收，不参与游戏逻辑。

### 11.5 宝箱开盖动画（2026-11-18 追加）

- 资产升级 v4：`build_loot_box.py` v010 起把箱盖拆成独立网格 `GEO_Chest_Lid / _Lid_Iron / _Lid_Rope / _Lid_Paint`（tris 总数不变，材质仍 ≤6）；导出 `mdl_loot_box_<tier>_v4.glb`。
- 表现层（`view/unit_layer.gd`）：盖子网格挂到 `LidPivot`（后缘铰链 `(0, 0.64, 0.39)`）；`_sync_boxes` 每帧把 `box_lid_t[i]` 向目标推进（3.2/s），目标 = 1 当搜索中（`searching_box == i`）或已打开；`lid_pivot.rotation.x = t * 1.92`（110° 后翻），约 0.31 s 合盖→全开。已开箱不再压小尺寸（盖子状态本身就说明「翻过了」），兜底方块保留旧压小表现。
